The **expected value** of a random variable is its probability-weighted average outcome, and value functions and most learning objectives are defined as expected values.

---
## Definition
For a discrete random variable $X$:
$$
\boxed{\mathbb{E}[X] = \sum_{x} x\, P(X = x)}, \qquad \mathbb{E}[f(X)] = \sum_{x} f(x)\, P(X = x)
$$ where:
- **$x$:** A possible value of $X$.
- **$P(X = x)$:** Probability that $X$ takes the value $x$.
- **$f$:** Any function of $X$.

For a continuous variable the sum becomes an integral against the density, $\mathbb{E}[X] = \int x\, p(x)\, dx$. The notation $\mathbb{E}_{x \sim p}[f(x)]$ states the distribution explicitly. Two useful properties:
- **Linearity:** $\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$ for constants $a, b$.
- **Conditional expectation:** $\mathbb{E}[X \mid Y = y] = \sum_x x\, P(X = x \mid Y = y)$ averages $X$ only over outcomes where $Y = y$.
## Example
A lottery pays $X = 10$ with probability $0.2$ and $X = 0$ with probability $0.8$.
### Step 1: Expected payout
$$
\mathbb{E}[X] = 10 \times 0.2 + 0 \times 0.8 = 2
$$
### Step 2: Expected value of a function
With $f(X) = X^2$:
$$
\mathbb{E}[X^2] = 100 \times 0.2 + 0 \times 0.8 = 20
$$
Note that $\mathbb{E}[X^2] = 20 \neq (\mathbb{E}[X])^2 = 4$.
## Discussion
In reinforcement learning, a [value function](../../Machine%20Learning/Reinforcement%20Learning/Value%20Function.md) is the conditional expectation of the return given the state. When the distribution is unknown, expected values are approximated by sample averages (see [Monte Carlo Estimation](Monte%20Carlo%20Estimation.md)).
