The message function $M^{(k)}$ computes a vector message from neighbor $u$ to target node $v$ at layer $k$, using information about both endpoints and the connecting edge.
## Definition
$$m^{(k)}_{uv} = M^{(k)}\!\left(h^{(k)}_u,\, h^{(k)}_v,\, e_{uv}\right)$$
where:
- $h^{(k)}_u$, $h^{(k)}_v$: node embeddings of source and target at layer $k$
- $e_{uv}$: edge feature vector for edge $(u,v)$; omitted when edges carry no features
- $M^{(k)}$: a learnable function, common choices:
  - **Linear:** $m_{uv} = W_m h^{(k)}_u$ — projects only the source embedding; ignores the target and edge
  - **MLP:** $m_{uv} = \text{MLP}\!\left([h^{(k)}_u \Vert h^{(k)}_v \Vert e_{uv}]\right)$ — concatenates all inputs; $\Vert$ denotes concatenation
  - **Attention-weighted:** $m_{uv} = \alpha_{uv} W h^{(k)}_u$ — scales the message by a learned coefficient; see [Graph Attention Network](Graph%20Attention%20Network.md)
One message is computed per directed edge. Messages are not yet combined here; that is handled by [Aggregation](2.2-Aggregation.md).
---
## Example
Triangle graph with 3 nodes (see [Graph Representation](1-Graph%20Representation.md)). Linear message: $m_{uv} = W_m h_u$ where $W_m \in \mathbb{R}^{2 \times 2}$ is the identity for illustration.
$$
\text{Edge } 0\to1: m_{01} = W_m h_0 = h_0 = \begin{bmatrix}1 & 0\end{bmatrix}
$$
$$
\text{Edge } 1\to2: m_{12} = W_m h_1 = h_1 = \begin{bmatrix}0 & 1\end{bmatrix}
$$
$$
\text{Edge } 2\to0: m_{20} = W_m h_2 = h_2 = \begin{bmatrix}1 & 1\end{bmatrix}
$$
```python
import torch
import torch.nn as nn

# Node features [N, d] = [3, 2]
H = torch.tensor([[1.0, 0.0],
                  [0.0, 1.0],
                  [1.0, 1.0]])

# Edges: 0→1, 1→2, 2→0
edge_index = torch.tensor([[0, 1, 2],   # source
                            [1, 2, 0]])  # destination

src, dst = edge_index[0], edge_index[1]

# Linear message: m_uv = W_m @ h_u (projects source embedding)
W_m = nn.Linear(2, 2, bias=False)
nn.init.eye_(W_m.weight)  # identity weight for illustration

h_src = H[src]           # gather source features: [|E|, d] = [3, 2]
messages = W_m(h_src)    # [|E|, d] = [3, 2]

print("Message 0→1:", messages[0])  # [1, 0]
print("Message 1→2:", messages[1])  # [0, 1]
print("Message 2→0:", messages[2])  # [1, 1]
```
