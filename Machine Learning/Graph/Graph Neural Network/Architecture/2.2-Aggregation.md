The aggregation function $A^{(k)}$ collects all incoming messages for a node and reduces them to a single vector. It must be **permutation-invariant**: the order in which neighbors are visited must not affect the result.
## Definition
$$m^{(k)}_v = \bigoplus_{u \in \mathcal{N}(v)} m^{(k)}_{uv}$$
where $\bigoplus$ is a permutation-invariant reduction. Common choices:
- **Sum:** $m_v = \sum_{u \in \mathcal{N}(v)} m_{uv}$ — captures total neighborhood signal; magnitude grows with degree; expressively equivalent to the Weisfeiler-Lehman isomorphism test (Xu et al. 2019, GIN)
- **Mean:** $m_v = \frac{1}{|\mathcal{N}(v)|}\sum_{u} m_{uv}$ — normalized by degree; loses information about neighborhood size
- **Max:** $m_v = \max_{u} m_{uv}$ — element-wise maximum; selects the most prominent feature per dimension; loses count information
- **Attention:** $m_v = \sum_u \alpha_{uv} m_{uv}$, where $\alpha_{uv}$ are learned per-edge weights; see [Graph Attention Network](Graph%20Attention%20Network.md)
In practice, aggregation is implemented via `torch.scatter_add` (sum), index-based mean, or `torch.scatter` with `reduce='max'`, operating over the destination indices of the edge list.
---
## Example
Using the messages from [2.1-Message](2.1-Message.md): $m_{01} = [1,0]$, $m_{12} = [0,1]$, $m_{20} = [1,1]$. Aggregate with sum.
Node 0 receives message from node 2: $m_0 = m_{20} = [1, 1]$
Node 1 receives message from node 0: $m_1 = m_{01} = [1, 0]$
Node 2 receives message from node 1: $m_2 = m_{12} = [0, 1]$
```python
import torch

# Messages per directed edge [|E|, d] = [3, 2]
messages = torch.tensor([[1.0, 0.0],   # edge 0→1
                          [0.0, 1.0],   # edge 1→2
                          [1.0, 1.0]])  # edge 2→0

# Destination node for each edge (edge_index[1])
dst = torch.tensor([1, 2, 0])
N, d = 3, 2

# --- Sum aggregation ---
agg_sum = torch.zeros(N, d)
agg_sum.scatter_add_(0, dst.unsqueeze(1).expand(-1, d), messages)
print("Sum aggregation:\n", agg_sum)
# node 0: [1,1], node 1: [1,0], node 2: [0,1]

# --- Mean aggregation (divide by degree) ---
degree = torch.bincount(dst, minlength=N).float().clamp(min=1)
agg_mean = agg_sum / degree.unsqueeze(1)
print("Mean aggregation:\n", agg_mean)

# --- Max aggregation ---
agg_max = torch.full((N, d), float('-inf'))
agg_max.scatter_reduce_(0, dst.unsqueeze(1).expand(-1, d), messages, reduce='amax')
print("Max aggregation:\n", agg_max)
```
