The update function $U^{(k)}$ combines a node's current embedding with its aggregated message to produce the new embedding for the next layer.
## Definition
$$h^{(k+1)}_v = U^{(k)}\!\left(h^{(k)}_v,\, m^{(k+1)}_v\right)$$
where $m^{(k+1)}_v$ is the aggregated message from [Aggregation](2.2-Aggregation.md). Common forms:
- **Concatenate + Linear:** $h^{(k+1)}_v = \sigma\!\left(W\!\left[h^{(k)}_v \| m^{(k)}_v\right]\right)$ — concatenates current embedding and message, then applies a linear layer and non-linearity $\sigma$ (e.g. ReLU); $\|$ denotes concatenation
- **MLP:** $h^{(k+1)}_v = \text{MLP}\!\left([h^{(k)}_v \oplus m^{(k)}_v]\right)$ — same as above with multiple hidden layers
- **GRU:** $h^{(k+1)}_v = \text{GRU}\!\left(m^{(k)}_v,\, h^{(k)}_v\right)$ — treats the message as the GRU input and the current embedding as the hidden state; used in Gated Graph Neural Networks (Li et al. 2016)
- **Residual:** $h^{(k+1)}_v = \sigma\!\left(W m^{(k)}_v\right) + h^{(k)}_v$ — adds a skip connection from the current embedding; mitigates over-smoothing in deep GNNs
---
## Example
Triangle graph with 3 nodes. Concatenate-then-linear update with ReLU: input dimension $2d = 4$, output dimension $d = 2$.
$$
\left[h^{(0)}_v \| m^{(1)}_v\right] \xrightarrow{W \in \mathbb{R}^{2 \times 4},\, \text{ReLU}} h^{(1)}_v
$$
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# Current node embeddings [N, d] = [3, 2]
H = torch.tensor([[1.0, 0.0],
                  [0.0, 1.0],
                  [1.0, 1.0]])

# Aggregated messages from 2.2-Aggregation [N, d] = [3, 2]
# (sum aggregation result from the triangle example)
agg = torch.tensor([[1.0, 1.0],   # node 0 received from node 2
                    [1.0, 0.0],   # node 1 received from node 0
                    [0.0, 1.0]])  # node 2 received from node 1

# Concatenate [h || m] along feature dimension
combined = torch.cat([H, agg], dim=1)   # [N, 2d] = [3, 4]

# Linear update: W in R^{d x 2d}, bias omitted for clarity
update_fn = nn.Linear(4, 2, bias=False)
nn.init.eye_(update_fn.weight[:, :2])   # identity initialisation for illustration

H_new = F.relu(update_fn(combined))     # [N, d] = [3, 2]
print("Updated embeddings:\n", H_new.detach())
# Each row is the new embedding h^(1)_v, encoding one hop of neighbourhood info
```
