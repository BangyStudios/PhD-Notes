The **advantage function** measures how much better an action is than the policy's average behavior in a state, and it is the low-variance learning signal used by [actor-critic](Actor-Critic.md) methods.

---
## Definition
$$
\boxed{A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)}
$$ where:
- **$Q^\pi(s, a)$:** Expected return after taking $a$ in $s$ and then following $\pi$ (see [Value Function](Value%20Function.md)).
- **$V^\pi(s)$:** Expected return from $s$ when following $\pi$.

Positive $A$ means the action beats the policy's average; on average the advantage is zero, $\sum_a \pi(a \mid s)\, A^\pi(s, a) = 0$. In practice it is estimated by the one-step [TD error](Temporal%20Difference%20Learning.md):
$$
A^\pi(s_t, a_t) \approx \delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)
$$ where:
- **$V$:** Learned estimate of $V^\pi$.
- **$r_{t+1}$, $\gamma$:** Reward and discount factor.
## Example
Use the two-state MDP from [Markov Decision Process](Markov%20Decision%20Process.md) with $\gamma = 0.9$ and $\pi = $ "always stay", for which $V^\pi(s_1) = 0$, $V^\pi(s_2) = 10$, and $Q^\pi(s_1, \text{move}) = 9$.
### Step 1: Exact advantages in $s_1$
$$
A^\pi(s_1, \text{move}) = 9 - 0 = 9, \qquad A^\pi(s_1, \text{stay}) = 0 - 0 = 0
$$
### Step 2: TD estimate after moving
The transition $s_1 \xrightarrow{\text{move}} s_2$ gives reward 0:
$$
\delta = 0 + 0.9 \times 10 - 0 = 9
$$
which matches the exact advantage, because transitions are deterministic and the values are exact.
## Discussion
**Generalized advantage estimation (GAE)** trades bias against variance by averaging TD errors over several steps, $\hat{A}_t = \sum_{l=0}^{\infty} (\gamma \lambda)^l\, \delta_{t+l}$, where $\lambda \in [0, 1]$; $\lambda = 0$ gives the one-step TD error and $\lambda = 1$ gives the Monte Carlo return minus $V(s_t)$. It is the default estimator in [PPO](PPO.md).
