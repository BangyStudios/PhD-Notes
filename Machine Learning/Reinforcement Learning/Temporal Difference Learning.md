**Temporal difference (TD) learning** updates a value estimate toward a target built from the observed reward and the current estimate of the next state, so the agent learns after every step instead of waiting for the episode to end.

---
## Definition
The simplest form, **TD(0)**, updates the state value after each transition $(s_t, r_{t+1}, s_{t+1})$:
$$
\boxed{V(s_t) \leftarrow V(s_t) + \alpha\, \delta_t, \qquad \delta_t = r_{t+1} + \gamma\, V(s_{t+1}) - V(s_t)}
$$ where:
- **$V(s)$:** Current estimate of the [state value](Value%20Function.md).
- **$\alpha$:** Learning rate (step size).
- **$r_{t+1} + \gamma V(s_{t+1})$:** **TD target**, a one-step estimate of the [return](Discounted%20Return.md).
- **$\delta_t$:** **TD error**, the gap between the target and the current estimate.

Using an estimate ($V(s_{t+1})$) to update another estimate is called **bootstrapping**.
## Example
Current estimates $V(s_t) = 2$ and $V(s_{t+1}) = 4$; observed reward $r_{t+1} = 1$; $\gamma = 0.9$, $\alpha = 0.1$.
### Step 1: TD target
$$
r_{t+1} + \gamma V(s_{t+1}) = 1 + 0.9 \times 4 = 4.6
$$
### Step 2: TD error
$$
\delta_t = 4.6 - 2 = 2.6
$$
### Step 3: Update
$$
V(s_t) \leftarrow 2 + 0.1 \times 2.6 = 2.26
$$
## Discussion
- **Monte Carlo** methods instead use the full observed return $G_t$ as the target (see [Monte Carlo Estimation](../../Math/Statistics/Monte%20Carlo%20Estimation.md)): unbiased but high-variance, and only available at episode end. TD targets are biased by the current estimate but have much lower variance.
- Applying the same idea to action values gives [SARSA](SARSA.md) and [Q-Learning](Q-Learning.md); the TD error is also the critic signal in [Actor-Critic](Actor-Critic.md).
