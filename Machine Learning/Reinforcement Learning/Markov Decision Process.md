A **Markov decision process (MDP)** is the mathematical model of a sequential decision problem that reinforcement learning assumes, specifying the states, actions, transition probabilities, and rewards.

---
## Definition
An MDP is a tuple:
$$
\mathcal{M} = (\mathcal{S}, \mathcal{A}, P, R, \gamma)
$$ where:
- **$\mathcal{S}$:** Set of states.
- **$\mathcal{A}$:** Set of actions.
- **$P(s' \mid s, a)$:** **Transition probability** of moving to state $s'$ after taking action $a$ in state $s$.
- **$R(s, a)$:** Expected immediate reward for taking action $a$ in state $s$.
- **$\gamma \in [0, 1)$:** **Discount factor** that weights future rewards (see [Discounted Return](Discounted%20Return.md)).

The defining assumption is the **Markov property**: the next state depends only on the current state and action, not on the earlier history:
$$
\boxed{P(s_{t+1} \mid s_t, a_t, s_{t-1}, a_{t-1}, \dots, s_0, a_0) = P(s_{t+1} \mid s_t, a_t)}
$$ where:
- **$s_t, a_t$:** State and action at time $t$.
## Example
### Step 1: Define the two-state MDP
Let $\mathcal{S} = \{s_1, s_2\}$ and $\mathcal{A} = \{\text{stay}, \text{move}\}$. Transitions are deterministic: $\text{stay}$ keeps the current state and $\text{move}$ switches to the other state. The only reward is for staying in $s_2$:
$$
R(s_2, \text{stay}) = 1, \qquad R(s_1, \text{stay}) = R(s_1, \text{move}) = R(s_2, \text{move}) = 0
$$
### Step 2: Roll out a trajectory
Starting in $s_1$ and choosing $\text{move}$, then $\text{stay}$:
$$
s_1 \xrightarrow{\text{move},\; r_1 = 0} s_2 \xrightarrow{\text{stay},\; r_2 = 1} s_2
$$
The best behavior is clearly to move to $s_2$ once and then stay forever. This MDP is reused in [Value Function](Value%20Function.md), [Bellman Equation](Bellman%20Equation.md), and [Q-Learning](Q-Learning.md).
## Discussion
- **Episodic vs. continuing:** episodic tasks end in a **terminal state**; continuing tasks run forever and need $\gamma < 1$ to keep returns finite.
- **Partial observability:** if the agent sees only an observation rather than the full state, the problem is a **POMDP** (partially observable MDP), and the Markov property holds only for the hidden state.
