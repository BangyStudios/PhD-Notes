A **deep Q-network (DQN)** replaces the [Q-learning](Q-Learning.md) table with a neural network $Q(s, a; \theta)$, which lets Q-learning scale to large state spaces such as raw game pixels.

---
## Definition
The network takes a state and outputs one Q-value per action. It is trained by minimizing the squared TD error over transitions sampled from a replay buffer:
$$
\boxed{\mathcal{L}(\theta) = \mathbb{E}_{(s, a, r, s') \sim \mathcal{D}} \left[ \left( y - Q(s, a; \theta) \right)^2 \right], \qquad y = r + \gamma \max_{a'} Q(s', a'; \theta^-)}
$$ where:
- **$\theta$:** Weights of the online Q-network, e.g. an [MLP](../Common%20Modules/Architectures/MLP.md) or a [CNN](../Convolution/CNN/CNN.md) for images.
- **$\mathcal{D}$:** [Experience replay](Experience%20Replay.md) buffer of past transitions.
- **$(s, a, r, s')$:** State, action taken, reward, and next state.
- **$y$:** TD target; $y = r$ if $s'$ is terminal.
- **$\theta^-$:** Weights of the [target network](Target%20Network.md), a slowly updated copy of $\theta$.
- **$\gamma$:** Discount factor.
## Example
Actions are $\{\text{left}, \text{right}\}$. For one sampled transition the agent took $a = \text{right}$, received $r = 1$, and $\gamma = 0.9$. The online network gives $Q(s, \cdot\,; \theta) = [1.0,\, 2.0]$ and the target network gives $Q(s', \cdot\,; \theta^-) = [3.0,\, 0.5]$.
### Step 1: TD target
$$
y = 1 + 0.9 \times \max(3.0,\, 0.5) = 1 + 2.7 = 3.7
$$
### Step 2: Loss
Only the output for the action taken enters the loss:
$$
\mathcal{L} = (3.7 - 2.0)^2 = 1.7^2 = 2.89
$$
### Step 3: Gradient on the output
$$
\frac{\partial \mathcal{L}}{\partial Q(s, \text{right}; \theta)} = -2\,(3.7 - 2.0) = -3.4
$$
The gradient is negative, so a [gradient descent step](../Training/7-Optimization_Step.md) raises $Q(s, \text{right})$ toward $3.7$; $\theta^-$ is not updated by this step.
## Discussion
- Experience replay and the target network are the two tricks that made the original Atari DQN (Mnih et al., 2015) stable; without them the targets and the data both shift with every update.
- **Double DQN** picks $a'$ with the online network and evaluates it with the target network, reducing overestimation.
- DQN needs a discrete action set because it takes a $\max$ over actions; continuous control uses [actor-critic](Actor-Critic.md) methods instead.
