A **target network** is a slowly updated copy of a value network that is used to compute TD targets, which stops the regression target from shifting every time the online network changes.

---
## Definition
The target weights $\theta^-$ follow the online weights $\theta$ either by a periodic copy (**hard update**) or by a running average (**soft** or **Polyak update**):
$$
\theta^- \leftarrow \theta \;\;\text{every } C \text{ steps}, \qquad \text{or} \qquad \boxed{\theta^- \leftarrow \tau\, \theta + (1 - \tau)\, \theta^-}
$$ where:
- **$\theta$:** Weights of the online network, updated by gradient descent.
- **$\theta^-$:** Weights of the target network, never updated by gradients.
- **$C$:** Number of steps between hard copies (e.g. 10,000 in the original [DQN](DQN.md)).
- **$\tau \in (0, 1]$:** Soft-update rate, typically $0.005$ to $0.01$.
## Example
One weight with online value $\theta = 2.0$, target value $\theta^- = 1.0$, and $\tau = 0.01$.
### Step 1: Soft update
$$
\theta^- \leftarrow 0.01 \times 2.0 + 0.99 \times 1.0 = 0.02 + 0.99 = 1.01
$$
The target moves only 1% of the way toward the online weight each step.
## Discussion
Without a target network, the TD target $r + \gamma \max_{a'} Q(s', a'; \theta)$ changes with every gradient step on $\theta$, and training can oscillate or diverge. Hard updates are used in DQN; soft updates are standard in continuous-control [actor-critic](Actor-Critic.md) methods such as DDPG and SAC.
