A **value function** estimates the return an agent can expect from a state, or from a state–action pair, when it follows a given policy.

---
## Definition
The **state-value function** and the **action-value function** (or **Q-function**) of a [policy](Policy.md) $\pi$ are:
$$
V^\pi(s) = \mathbb{E}_\pi\!\left[G_t \mid s_t = s\right], \qquad Q^\pi(s, a) = \mathbb{E}_\pi\!\left[G_t \mid s_t = s,\, a_t = a\right]
$$ where:
- **$G_t$:** [Discounted return](Discounted%20Return.md) from time $t$.
- **$\mathbb{E}_\pi$:** [Expectation](../../Math/Statistics/Expected%20Value.md) over trajectories generated by following $\pi$.
- **$V^\pi(s)$:** Expected return starting in $s$ and following $\pi$.
- **$Q^\pi(s, a)$:** Expected return after taking action $a$ in $s$, then following $\pi$.

The two are linked by $V^\pi(s) = \sum_a \pi(a \mid s)\, Q^\pi(s, a)$. The **optimal** value functions are the best achievable over all policies, and acting greedily on $Q^*$ gives an optimal policy:
$$
\boxed{V^*(s) = \max_\pi V^\pi(s), \qquad Q^*(s, a) = \max_\pi Q^\pi(s, a), \qquad \pi^*(s) = \arg\max_a Q^*(s, a)}
$$
## Example
Use the two-state MDP from [Markov Decision Process](Markov%20Decision%20Process.md) ($\text{stay}$ in $s_2$ earns 1, everything else earns 0), with $\gamma = 0.9$ and the policy $\pi = $ "always stay".
### Step 1: Value of $s_2$
Staying in $s_2$ earns 1 every step:
$$
V^\pi(s_2) = 1 + 0.9 + 0.9^2 + \dots = \frac{1}{1 - 0.9} = 10
$$
### Step 2: Value of $s_1$
Staying in $s_1$ earns 0 forever, so $V^\pi(s_1) = 0$.
### Step 3: Action value of moving once
Take $\text{move}$ from $s_1$ (reward 0), then follow $\pi$ from $s_2$:
$$
Q^\pi(s_1, \text{move}) = 0 + 0.9 \times V^\pi(s_2) = 0.9 \times 10 = 9
$$
Since $Q^\pi(s_1, \text{move}) = 9 > V^\pi(s_1) = 0$, switching to $\text{move}$ in $s_1$ improves the policy; this comparison is the [advantage](Advantage%20Function.md).
## Discussion
Value functions satisfy recursive [Bellman equations](Bellman%20Equation.md), which is what makes them learnable from single transitions with [temporal difference learning](Temporal%20Difference%20Learning.md).
