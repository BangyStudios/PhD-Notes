**SARSA** is an on-policy [temporal difference](Temporal%20Difference%20Learning.md) algorithm that learns the action values of the policy the agent is actually following, named after the tuple $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ each update uses.

---
## Definition
$$
\boxed{Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma\, Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t) \right]}
$$ where:
- **$Q(s, a)$:** Current estimate of the [action value](Value%20Function.md).
- **$a_{t+1}$:** Next action, actually chosen by the current (e.g. [ε-greedy](Epsilon-Greedy.md)) policy.
- **$\alpha$, $\gamma$:** Learning rate and discount factor.

The only difference from [Q-Learning](Q-Learning.md) is that the target uses $Q(s_{t+1}, a_{t+1})$ instead of $\max_{a'} Q(s_{t+1}, a')$.
## Example
Current values $Q(s_t, a_t) = 1$, $Q(s_{t+1}, \text{stay}) = 2$, $Q(s_{t+1}, \text{move}) = 5$; reward $r_{t+1} = 0$; $\gamma = 0.9$, $\alpha = 0.5$. The ε-greedy policy happens to explore and picks $a_{t+1} = \text{stay}$.
### Step 1: SARSA update
$$
Q(s_t, a_t) \leftarrow 1 + 0.5\,[0 + 0.9 \times 2 - 1] = 1 + 0.5 \times 0.8 = 1.4
$$
### Step 2: Q-learning update, for comparison
$$
Q(s_t, a_t) \leftarrow 1 + 0.5\,[0 + 0.9 \times 5 - 1] = 1 + 0.5 \times 3.5 = 2.75
$$
SARSA accounts for the fact that the agent sometimes explores; Q-learning assumes the best action will be taken.
## Discussion
Because SARSA values include the cost of exploratory mistakes, it learns safer behavior near hazards. In the classic **cliff-walking** task, SARSA learns a path away from the cliff edge while Q-learning learns the shortest path along the edge and falls off more often while exploring.
