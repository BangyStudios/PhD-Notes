The **return** is the discounted sum of rewards an agent collects from a given time step onward, and it is the quantity reinforcement learning tries to maximize.

---
## Definition
$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \dots = \sum_{k=0}^{\infty} \gamma^k\, r_{t+k+1}
$$ where:
- **$G_t$:** Return from time step $t$.
- **$r_{t+k+1}$:** Reward received $k+1$ steps after time $t$.
- **$\gamma \in [0, 1)$:** **Discount factor**; a reward $k$ steps in the future is worth $\gamma^k$ times as much as an immediate one.

Factoring out the first reward gives the recursive form used by every [Bellman equation](Bellman%20Equation.md):
$$
\boxed{G_t = r_{t+1} + \gamma\, G_{t+1}}
$$
## Example
An episode yields rewards $r_1 = 0$, $r_2 = 1$, $r_3 = 1$ and then ends, with $\gamma = 0.9$.
### Step 1: Direct sum
$$
G_0 = 0 + 0.9 \times 1 + 0.9^2 \times 1 = 0 + 0.9 + 0.81 = 1.71
$$
### Step 2: Recursive form, working backward
$$
G_2 = r_3 = 1, \qquad G_1 = r_2 + \gamma G_2 = 1 + 0.9 \times 1 = 1.9, \qquad G_0 = r_1 + \gamma G_1 = 0 + 0.9 \times 1.9 = 1.71
$$
Both methods agree.
## Discussion
- If every reward satisfies $|r| \le r_{\max}$, then $|G_t| \le r_{\max} / (1 - \gamma)$, so $\gamma < 1$ keeps infinite sums finite.
- A small $\gamma$ makes the agent short-sighted; a $\gamma$ close to 1 makes it value long-term outcomes.
