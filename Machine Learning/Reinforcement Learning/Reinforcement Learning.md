**Reinforcement learning (RL)** is a learning paradigm in which an **agent** learns by trial and error which actions to take in an **environment** so as to maximize the total reward it receives.

---
## Definition
At each time step $t$ the agent observes a state, picks an action, and the environment returns a reward and a next state:
$$
s_t \;\xrightarrow{\;a_t \sim \pi(\cdot \mid s_t)\;}\; (r_{t+1},\, s_{t+1})
$$ where:
- **$s_t$:** State of the environment at time $t$.
- **$a_t$:** Action chosen by the agent at time $t$.
- **$\pi$:** The agent's [policy](Policy.md), a rule for choosing actions.
- **$r_{t+1}$:** Scalar **reward** received after taking $a_t$.
- **$s_{t+1}$:** Next state.

The environment is formalized as a [Markov decision process](Markov%20Decision%20Process.md), and the agent's goal is to find the policy with the highest [expected](../../Math/Statistics/Expected%20Value.md) [discounted return](Discounted%20Return.md):
$$
\boxed{\pi^* = \arg\max_{\pi}\, \mathbb{E}_{\pi}\!\left[G_0\right]}
$$ where:
- **$\pi^*$:** Optimal policy.
- **$G_0$:** Discounted sum of all rewards from the start of the episode.
- **$\mathbb{E}_{\pi}$:** Expectation over trajectories generated by following $\pi$.
## Example
### Step 1: Define a tiny episode
A robot in a corridor starts at state $s_0$, takes action $a_0 = \text{right}$, receives $r_1 = 0$ and lands in $s_1$; it then takes $a_1 = \text{right}$, receives $r_2 = 5$ for reaching the goal, and the episode ends.
### Step 2: Compute the total reward
With no discounting ($\gamma = 1$):
$$
G_0 = r_1 + r_2 = 0 + 5 = 5
$$
The agent learns to repeat actions that led to high $G_0$, even though the first action earned nothing on its own.
## Discussion
Unlike supervised learning, there are no labeled correct actions: the agent only sees rewards, which may be delayed, and the data it sees depends on its own choices. Methods fall into three families:
- **Value-based:** learn a [value function](Value%20Function.md) and act greedily on it.
	- [Temporal Difference Learning](Temporal%20Difference%20Learning.md), [Q-Learning](Q-Learning.md), [SARSA](SARSA.md), [DQN](DQN.md).
- **Policy-based:** optimize the policy directly.
	- [Policy Gradient](Policy%20Gradient.md).
- **Actor-critic:** learn both a policy and a value function.
	- [Actor-Critic](Actor-Critic.md), [PPO](PPO.md).

Supporting concepts: [Bellman Equation](Bellman%20Equation.md), [Epsilon-Greedy](Epsilon-Greedy.md), [Advantage Function](Advantage%20Function.md), [Experience Replay](Experience%20Replay.md), [Target Network](Target%20Network.md). Methods that learn from sampled experience without knowing the transition probabilities are called **model-free**; methods that learn or use a model of the environment are **model-based**.
