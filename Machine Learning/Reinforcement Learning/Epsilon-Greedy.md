**ε-greedy** is the simplest exploration strategy: it picks a random action with small probability $\varepsilon$ and the best-known action otherwise, balancing **exploration** (trying actions to learn about them) against **exploitation** (using what is already known).

---
## Definition
$$
\pi(a \mid s) =
\begin{cases}
1 - \varepsilon + \dfrac{\varepsilon}{|\mathcal{A}|} & \text{if } a = \arg\max_{a'} Q(s, a') \\[2mm]
\dfrac{\varepsilon}{|\mathcal{A}|} & \text{otherwise}
\end{cases}
$$ where:
- **$\varepsilon \in [0, 1]$:** Exploration probability.
- **$|\mathcal{A}|$:** Number of actions.
- **$Q(s, a)$:** Current estimate of the [action value](Value%20Function.md).

The greedy action also gets $\varepsilon / |\mathcal{A}|$ because the random choice can land on it.
## Example
Four actions, $\varepsilon = 0.1$, and action $a_2$ has the highest $Q$-value.
### Step 1: Non-greedy actions
$$
\pi(a_1 \mid s) = \pi(a_3 \mid s) = \pi(a_4 \mid s) = \frac{0.1}{4} = 0.025
$$
### Step 2: Greedy action
$$
\pi(a_2 \mid s) = 1 - 0.1 + 0.025 = 0.925
$$
Check: $0.925 + 3 \times 0.025 = 1$.
## Discussion
- $\varepsilon$ is usually decayed over training, e.g. from 1.0 to 0.05, so the agent explores early and exploits later.
- **Boltzmann exploration** samples from a [softmax](../Common%20Modules/Primitives/Softmax.md) over $Q$-values instead, so better actions are tried more often than clearly bad ones.
