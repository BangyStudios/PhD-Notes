An **actor-critic** method combines a policy (the **actor**) that chooses actions with a value function (the **critic**) that evaluates them, replacing the noisy sampled return of [policy gradient](Policy%20Gradient.md) with a learned, lower-variance signal.

---
## Definition
After each transition $(s_t, a_t, r_{t+1}, s_{t+1})$, compute the TD error with the critic and use it to update both networks:
$$
\delta_t = r_{t+1} + \gamma V_w(s_{t+1}) - V_w(s_t)
$$
$$
\boxed{w \leftarrow w + \alpha_w\, \delta_t\, \nabla_w V_w(s_t), \qquad \theta \leftarrow \theta + \alpha_\theta\, \delta_t\, \nabla_\theta \log \pi_\theta(a_t \mid s_t)}
$$ where:
- **$\pi_\theta$:** Actor, the [policy](Policy.md) with parameters $\theta$.
- **$V_w$:** Critic, an estimate of the [state value](Value%20Function.md) with parameters $w$.
- **$\delta_t$:** [TD error](Temporal%20Difference%20Learning.md), used as an estimate of the [advantage](Advantage%20Function.md).
- **$\alpha_w$, $\alpha_\theta$:** Learning rates of the critic and actor.
- **$\gamma$:** Discount factor.
## Example
Two actions with a [softmax](../Common%20Modules/Primitives/Softmax.md) actor, logits $\theta = [0, 0]$ so $\pi = [0.5, 0.5]$. The critic is a table with $V(s) = 1$ and $V(s') = 2$. The agent takes $a_1$, gets $r = 0.5$, and lands in $s'$; $\gamma = 0.9$ and $\alpha_w = \alpha_\theta = 0.1$.
### Step 1: TD error
$$
\delta = 0.5 + 0.9 \times 2 - 1 = 1.3
$$
### Step 2: Critic update
For a table entry, $\nabla_w V_w(s) = 1$:
$$
V(s) \leftarrow 1 + 0.1 \times 1.3 = 1.13
$$
### Step 3: Actor update
With $\nabla_\theta \log \pi(a_1) = [1 - 0.5,\; 0 - 0.5] = [0.5,\, -0.5]$:
$$
\theta \leftarrow [0, 0] + 0.1 \times 1.3 \times [0.5,\, -0.5] = [0.065,\, -0.065]
$$
The new probability of $a_1$ is $e^{0.065} / (e^{0.065} + e^{-0.065}) \approx 0.532$: the action did better than the critic expected, so it is reinforced.
## Discussion
- **A2C** (advantage actor-critic) runs several environments in parallel and updates synchronously; **A3C** does so asynchronously.
- [PPO](PPO.md) adds a clipped objective so each batch can be reused for several updates.
- For continuous actions, **DDPG** and **SAC** pair an actor with a Q-function critic, reusing [Experience Replay](Experience%20Replay.md) and [Target Networks](Target%20Network.md) from [DQN](DQN.md).
- The actor and critic often share a network backbone with two output heads.
