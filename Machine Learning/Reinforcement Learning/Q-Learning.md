**Q-learning** is an off-policy [temporal difference](Temporal%20Difference%20Learning.md) algorithm that learns the optimal action-value function $Q^*$ directly from experience, without a model of the environment.

---
## Definition
After each transition $(s_t, a_t, r_{t+1}, s_{t+1})$, update a table of Q-values:
$$
\boxed{Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \left[ r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \right]}
$$ where:
- **$Q(s, a)$:** Current estimate of the [action value](Value%20Function.md).
- **$\alpha$:** Learning rate.
- **$\gamma$:** Discount factor.
- **$\max_{a'} Q(s_{t+1}, a')$:** Value of the best action in the next state; it is $0$ if $s_{t+1}$ is terminal.

The target is a sampled version of the [Bellman optimality equation](Bellman%20Equation.md). Actions are usually chosen with [ε-greedy](Epsilon-Greedy.md).
## Example
Use the two-state MDP from [Markov Decision Process](Markov%20Decision%20Process.md) ($\text{stay}$ in $s_2$ earns 1, everything else earns 0), with $\alpha = 0.5$, $\gamma = 0.9$, and all Q-values starting at 0.
### Step 1: Move from $s_1$ to $s_2$, reward 0
$$
Q(s_1, \text{move}) \leftarrow 0 + 0.5\,[0 + 0.9 \times 0 - 0] = 0
$$
### Step 2: Stay in $s_2$, reward 1
$$
Q(s_2, \text{stay}) \leftarrow 0 + 0.5\,[1 + 0.9 \times 0 - 0] = 0.5
$$
### Step 3: Stay in $s_2$ again, reward 1
$$
Q(s_2, \text{stay}) \leftarrow 0.5 + 0.5\,[1 + 0.9 \times 0.5 - 0.5] = 0.5 + 0.5 \times 0.95 = 0.975
$$
### Step 4: New episode, move from $s_1$ to $s_2$ again
$$
Q(s_1, \text{move}) \leftarrow 0 + 0.5\,[0 + 0.9 \times 0.975 - 0] = 0.5 \times 0.8775 \approx 0.439
$$
The reward found in $s_2$ has propagated back to the action that leads there. With more updates the values approach $Q^*(s_2, \text{stay}) = 10$ and $Q^*(s_1, \text{move}) = 9$.
## Discussion
- **Off-policy:** the target uses $\max_{a'}$ regardless of which action the agent actually takes next, so Q-learning learns the greedy policy while behaving ε-greedily. Compare [SARSA](SARSA.md).
- **Convergence:** the table converges to $Q^*$ if every state–action pair is visited infinitely often and $\alpha$ decays appropriately.
- **Limits:** a table cannot cover large or continuous state spaces, which motivates [DQN](DQN.md). The $\max$ also overestimates noisy values; **Double Q-learning** fixes this by using one estimate to choose the action and another to evaluate it.
