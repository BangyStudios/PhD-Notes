A **policy** is the agent's rule for choosing an action in each state, and finding a good policy is the end goal of reinforcement learning.

---
## Definition
A **stochastic policy** gives a probability distribution over actions for every state:
$$
\pi(a \mid s) = P(a_t = a \mid s_t = s), \qquad \sum_{a \in \mathcal{A}} \pi(a \mid s) = 1
$$ where:
- **$\pi(a \mid s)$:** Probability of choosing action $a$ in state $s$.
- **$\mathcal{A}$:** Set of actions.

A **deterministic policy** maps each state to a single action, $a = \mu(s)$. In deep RL the policy is a neural network with parameters $\theta$, often a [softmax](../Common%20Modules/Primitives/Softmax.md) over action scores:
$$
\pi_\theta(a \mid s) = \frac{\exp(z_a)}{\sum_{b \in \mathcal{A}} \exp(z_b)}, \qquad \mathbf{z} = f_\theta(s)
$$ where:
- **$f_\theta$:** Network that maps a state to one score (logit) per action.
- **$z_a$:** Score of action $a$.
## Example
### Step 1: Compute the action scores
In state $s$, a network outputs scores $\mathbf{z} = [z_{\text{left}}, z_{\text{right}}] = [1, 0]$.
### Step 2: Apply the softmax
$$
\pi(\text{left} \mid s) = \frac{e^1}{e^1 + e^0} = \frac{2.718}{3.718} \approx 0.731, \qquad \pi(\text{right} \mid s) = \frac{1}{3.718} \approx 0.269
$$
The agent samples $\text{left}$ about 73% of the time; a greedy deterministic policy would always pick $\text{left}$.
## Discussion
- **Behavior vs. target policy:** the **behavior policy** generates the data; the **target policy** is the one being learned. An algorithm is **on-policy** if the two are the same (e.g. [SARSA](SARSA.md)) and **off-policy** if they differ (e.g. [Q-Learning](Q-Learning.md)).
- Value-based methods derive the policy from a [value function](Value%20Function.md); [policy gradient](Policy%20Gradient.md) methods learn $\pi_\theta$ directly.
